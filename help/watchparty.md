# WatchParty

## ¿Cómo funciona?

Una sala compartida, sincronizada en tiempo real.

### Crear y compartir

1. El anfitrión crea una sala.
2. Comparte el código con sus amigos.

### Unirse

3. Los invitados ingresan el código para unirse.

### Durante la sala

4. La reproducción, las pausas y el contenido se sincronizan automáticamente.
5. Si el anfitrión sale, el rol se transfiere automáticamente.
